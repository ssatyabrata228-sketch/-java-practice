# Java Practice & Interview Preparation

A structured Java practice repository covering **Core Java, problem solving, Object-Oriented Programming, Collections, Strings, Searching & Sorting, Recursion, and interview-style DSA problems**.

> **Goal:** Build strong Java fundamentals through consistent hands-on problem solving and write clean, readable solutions that can be discussed in technical interviews.

## 💡 How Each Problem Should Be Practiced

For every problem, try to answer these questions before looking at the solution:

1. What is the input and expected output?
2. What is the simplest approach?
3. Can the solution be optimized?
4. What are the time and space complexities?
5. What edge cases can break the solution?
